# Makes predictions from a MLlib model
`predict.Rd`
Makes predictions from a MLlib model. For more information, see the specific MLlib model below.
## Usage[](https://spark.apache.org/docs/latest/api/R/reference/predict.html#ref-usage)

```
predict(object, ...)
```

## Arguments[](https://spark.apache.org/docs/latest/api/R/reference/predict.html#arguments)

object

a fitted ML model object.

...

additional argument(s) passed to the method.
