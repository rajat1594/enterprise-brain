# Saves the MLlib model to the input path
`write.ml.Rd`
Saves the MLlib model to the input path. For more information, see the specific MLlib model below.
## Usage[](https://spark.apache.org/docs/latest/api/R/reference/write.ml.html#ref-usage)

```
write.ml(object, path, ...)
```

## Arguments[](https://spark.apache.org/docs/latest/api/R/reference/write.ml.html#arguments) 

object
    
a fitted ML model object. 

path
    
the directory where the model is saved. 

...
    
additional argument(s) passed to the method.
