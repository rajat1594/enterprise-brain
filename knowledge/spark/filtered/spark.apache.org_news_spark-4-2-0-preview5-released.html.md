# Preview release of Spark 4.2.0
To enable wide-scale community testing of the upcoming Spark 4.2.0 release, the Apache Spark community has posted a [Spark 4.2.0-preview5 release](https://dist.apache.org/repos/dist/release/spark/spark-4.2.0-preview5). This preview is not a stable release in terms of either API or functionality, but it is meant to give the community early access to try the code that will become Spark 4.2.0. If you would like to test the release, please [download](https://dist.apache.org/repos/dist/release/spark/spark-4.2.0-preview5) it, and send feedback using either [mailing lists](https://spark.apache.org/community.html) or [JIRA](https://issues.apache.org/jira/browse/SPARK/?selectedTab=com.atlassian.jira.jira-projects-plugin:summary-panel). The documentation is available at the [link](https://spark.apache.org/docs/4.2.0-preview5/).
We’d like to thank our contributors and users for their contributions and early feedback to this release. This release would not have been possible without you.
